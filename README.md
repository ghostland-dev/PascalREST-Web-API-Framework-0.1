# PascalREST-Web-API-Framework-0.1
 PascalREST is a FreePascal language micro framework that helps you quickly write simple yet powerful and fast web applications and APIs.
 
Welcome
PascalREST is a FreePascal micro framework that helps you quickly write simple yet powerful web applications and APIs. At its core, Slim is a dispatcher that receives an HTTP request, invokes an appropriate callback routine, and returns an HTTP response. That’s it.

What’s the point?
PascalREST is an ideal tool to create APIs that consume, repurpose, or publish data. PascalREST is also a great tool for rapid prototyping. Heck, you can even build full-featured web applications with user interfaces. More importantly, PascalREST is super fast and has very little code.

At its core, PascalREST is a dispatcher that receives an HTTP request, invokes an appropriate callback routine, and returns an HTTP response. That’s it.

You don’t always need a kitchen-sink solution like commun Frameworks like Expressjs or Laravel. These are great tools, for sure. But they are often overkill. Instead, PascalREST provides only a minimal set of tools that do what you need and nothing else.
